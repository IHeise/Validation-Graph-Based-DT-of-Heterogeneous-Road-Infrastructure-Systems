\# Database Constraint Definitions



This directory contains the database constraint definitions used in the setup for the synthetic experiments.



\## Files



* sos-bridge-i\_constraints.csv
* sos-road-i\_constraints.csv
* sos-traffic-i\_constraints.csv
* sos-infranet-i\_constraints.csv
* mono-big\_constraints.csv
* mono-reduced\_constraints.csv





Each CSV contains the following columns:



* Constraint\_Name
* Constraint\_Type
* Constraint\_Label
* Constraint\_Property



Composite constraint properties are stored as comma-separated values within a single field.
